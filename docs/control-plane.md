# Control plane

`apps/web` — Next.js App Router. Страницы только принимают HTTP и зовут пакеты. Создание агента собрано в `src/lib/create-agent.ts`.

Без сессии страницы приложения уводят на `/login`. Сессия better-auth, email и пароль, минимум 8 символов. После регистрации у пользователя уже есть личный тенант.

## Страницы

| Путь | Что на ней |
| --- | --- |
| `/login`, `/register` | Вход и регистрация. |
| `/forgot-password`, `/reset-password` | Сброс пароля по ссылке из письма. Ссылка живёт час, после смены пароля все сессии пользователя закрываются. Без `MAILGUN_API_KEY` письмо не уходит, ссылка пишется в лог сервера строкой `[auth] … ссылка сброса пароля`. |
| `/` | Агенты тенанта и форма создания. Пока машина поднимается, список обновляется сам. |
| `/agents/[id]` | Сверху почта для инвайтов и кнопка Google. Ниже список чатов и открытый чат, тумблер «Разрешать все действия без человека» (по умолчанию выключен). Ниже сервисы, живой экран браузера, пока сессия открыта, логи задач с видео, таблица токенов и денег. Открытый чат — в `?chat=`. |

Карточка один раз будит машину (`?wake=1`) и дальше слушает `GET /api/agents/:id/events`. Раз в 30 секунд обновляется только строка агента, спящую машину этот опрос не будит. Если машина `suspended`, поток отдаёт одно событие `asleep` и `retry: 15000`, не открывая runtime. Пока агент в браузере, карточка показывает iframe Live View. Видео после сессии отдаётся через control plane: сам runtime снаружи не открыт.

## API для браузера

Всё под сессией. Агент читается только внутри тенанта зрителя.

| Метод | Путь | |
| --- | --- | --- |
| GET, POST | `/api/agents` | Список. Создание: `{ name, model, localPart? }`. |
| GET | `/api/agents/:id` | Карточка и снимок runtime. Опрос не будит спящую машину: в ответе `asleep: true`. `?wake=1` будит. Если машина молчит, в ответе `runtimeError`, страница всё равно открывается. |
| PATCH | `/api/agents/:id` | `autonomous`, `model`. Смена модели переписывает `config.yaml` и обновляет машину. |
| DELETE | `/api/agents/:id` | Гасит Fly-приложение и удаляет запись. Адрес снова свободен. |
| POST | `/api/agents/:id/chat` | `{ message, chatId? }`. Автор — email вошедшего. Без `chatId` создаётся новый чат. |
| GET, POST | `/api/agents/:id/chats` | Список чатов. Создание: `{ title? }`. |
| GET, PATCH, DELETE | `/api/agents/:id/chats/:chatId` | Сообщения, переименование `{ title }`, удаление. |
| GET | `/api/agents/:id/events` | SSE-прокси к runtime. Спящую машину не будит. |
| POST | `/api/agents/:id/approvals/:approvalId` | `{ approved }`. |
| GET | `/api/agents/:id/runs/:runId` | Шаги задачи. |
| GET | `/api/agents/:id/browser-sessions/:sessionId/actions` | Журнал браузера. |
| GET | `/api/agents/:id/browser-sessions/:sessionId/video` | MP4. |
| GET | `/api/agents/:id/google` | Редирект на согласие Google. |
| GET | `/api/google/callback` | Код меняется на refresh token, токен шифруется в базу, `google_token.json` кладётся на машину. |
| GET | `/api/models` | Модели OpenRouter, у которых есть tools. Кэш 10 минут. |
| * | `/api/auth/*` | better-auth. |

Google OAuth: Gmail, Calendar, Drive и email. `state` — зашифрованный `{ agentId, tenantId, at }`, живёт 15 минут и должен совпасть с тенантом сессии. Свой `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET`, redirect `{APP_URL}/api/google/callback`.

## API для runtime

Без сессии пользователя. `Authorization: Bearer <runtime token>` и `X-Agent-Id`. Токен сравнивается с расшифрованным из базы.

| Метод | Путь | |
| --- | --- | --- |
| POST | `/api/runtime/send-email` | Письмо с адреса этого агента через Mailgun. |
| POST | `/api/runtime/report` | `type: recipe` пишет общий каталог, и снимок рассылается запущенным агентам тенанта. `type: credential` пишет секрет этого агента, и свежий снимок получает только он. |
| POST | `/api/runtime/suspend` | Усыпить машину этого агента. Ответ уходит сразу, `suspend` — после него. |

Почта снаружи — `POST /webhooks/email`. Правила входа в [почте](mail.md).

## Создание агента

1. Домен: свой домен тенанта или `AGENTS_DOMAIN`. Локальная часть из логина владельца и имени агента (`login.agent.name`) или целиком из запроса. Занятая получает числовой суффикс.
2. В базу сразу пишется запись `creating` и случайный runtime-токен, в колонке он уже зашифрован.
3. Ответ клиенту уходит не дожидаясь машины. Дальше в фоне: приложение `swarm-<id>`, приватный адрес Flycast, volume 3 GB, Machine с двумя контейнерами. Статус по дороге — `provisioning`, текст шага виден в списке.
4. Когда машина дошла до `started`, статус `running`, `runtimeUrl` — `http://<app>.flycast:8787`.
5. Любая ошибка этого фона ставит `failed` и текст ошибки. Запись и адрес остаются, пока агента не удалят.

Без `FLY_API_TOKEN` или `OPENROUTER_API_KEY` создание останавливается с понятной ошибкой. Список и вход при этом работают.

Удаление ставит `deleting`, сносит Fly-приложение вместе с диском и убирает строку. Отзывать в Mailgun нечего. Google refresh token уходит вместе с записью.

Смена модели или автономности пишется в базу. Автономность ещё уходит в runtime живым запросом. Модель дополнительно пересобирает конфиг Hermes и обновляет машину: смена `config.yaml` попадает на диск при следующем старте контейнера.
